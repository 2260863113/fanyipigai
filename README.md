# 英语翻译练习站

面向「外研社·国才杯」英语组笔译赛项的**个人练习站**。核心不是刷题量，而是把「专家级批改反馈」变成肌肉记忆：你写下译文，AI 以校对符号的方式逐处批注——划掉错的、上方写对的、标红补上漏的、弧线表示语序调换——并给出分数与错误归类。

## 目标赛制的官方规格

以下数字来自公开赛事通知（[2026 校赛通知](https://wgyxy.cuit.edu.cn/info/1060/2390.htm)、[2025 校赛通知](https://gl.wzbc.edu.cn/Art/Art_188/Art_188_131036.aspx)），是本项目所有"字数""文体""评分尺子"的依据：

| 项目 | 规格 |
| --- | --- |
| 英译汉 | 250–350 词，建议 30 分钟，50 分 |
| 汉译英 | 200–300 字，建议 30 分钟，50 分 |
| 考查文体 | 政治文献、新闻编译、文学作品选篇、一般说明文 |
| 术语考查 | 习近平新时代中国特色社会主义思想关键术语、中华思想文化术语的翻译及阐释 |
| 素材来源 | 《习近平谈治国理政》各卷、《理解当代中国》系列教材 |

## 功能结构

- **两大方向**：中译英、英译中
- **四类题型**：术语翻译、句子翻译、段落翻译、文章翻译
  - 数据上各自独立（术语题没有"语序调换"，文章题要管篇长与段落），**共用同一个批注渲染器**
- **界面**：左右两栏。左栏显示待译原文，右栏是你写译文的地方。两栏顶部各有一个「参考译文」折叠开关
- **练习模式**：每道题可以自己选「先自己译」或「边看参考译文边练」
- **批改结果**：总分 + 四个维度分 + 错误分类统计 → 带批注的你的译文 → 点任意批注看"错在哪类、为什么错"

## 批注系统

五种改法，每种错误同时带「改法类型」和「错误分类」（一条错误只归一类，按固定优先级判定）：

| 改法类型 | 视觉表现 |
| --- | --- |
| 替换 | 原词加删除线，上方小字写正确写法 |
| 插入 | 在正确位置以标记补入（如缺失的冠词 `a`） |
| 删除 | 多余内容直接划掉 |
| 整句重写 | 整句加删除线，下方给出正确整句 |
| 语序调换 | 两段带编号的配对弧线 |

颜色分级：**红** = 语法错误与严重表达不当；**橙** = 表达生硬别扭；**绿** = 表达优秀（绿色单独记录，不计入错误统计）。

修改风格两档：**润色**（只改语法错误与严重表达不当）、**精修**（额外给出更好的表达）。

## 分数

对标比赛评分标准，每次批改固定输出：总分（0–100）+ 四个维度分 + 总体评语 + 各维度评语。

四个维度：**术语准确**、**语法正确**、**语篇连贯**、**语体得体**。

## 内容来源

- **官方原文**：人工核对过来源的文本
- **AI 生成**：按话题与文体生成，程序硬校验字数（英按词数、中按字符数），越界自动重新生成
- 话题预设：生态文明建设、科技、政策等常见领域，也可自行输入领域
- 术语表：由草稿起步，逐条对照教材人工校对；**未校对的条目不参与扣分**

> ⚠️ DeepSeek 模型不具备联网能力，不能"去抓一篇新华社文章"——那样只会编造出不存在的文章。AI 生成的内容只保证**文体、话题、字数**符合比赛要求，不代表真实新闻。

## 技术架构

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 运行时 | Cloudflare Workers + Static Assets | 通过官方 Vite 插件构建；D1 绑定只能在 Workers 上使用 |
| 前端 | React + TypeScript + Vite | |
| 数据库 | Cloudflare D1 | 题库、术语表、每次提交记录（含答题原文与完整批改） |
| AI | DeepSeek API（默认 `deepseek-flash`） | 开启 JSON 输出模式，返回结构化数据 |
| 密钥 | 本地 `.dev.vars` / 线上 Cloudflare Secrets | 均不入库 |
| 访问控制 | 全局口令 + 长期登录凭证 | 公网部署的必要防护 |

### 批改请求的走向

浏览器代码里**永远不出现 API 密钥**。提交批改时请求发给同源的 `/api/judge`：

```
浏览器 → /api/judge → 补上密钥 → api.deepseek.com → 解析校验 → 返回结构化批改
```

本地开发时 `/api/judge` 由 `vite-plugin-judge-api.ts` 提供（只从 `.dev.vars` 读密钥）；
部署到 Cloudflare 后同一路径由 Worker 承担，前端代码无需改动。

AI 返回的结果要经过 `src/domain/parse.ts` 的解析与 `src/domain/validate.ts` 的位置校验：
不合格时把**具体原因**回传给模型重试（最多 3 次），仍不合格就如实报错并保留你的输入。
单次批改实测约 10–35 秒（重试会明显变慢）。

## 本地开发

### 一键启动（推荐）

| 系统 | 怎么做 |
| --- | --- |
| Windows | **双击项目根目录的 `启动.bat`** |
| macOS / Linux | 终端执行 `./start.sh` |

脚本会依次检查 Node 版本、依赖是否装好、`.dev.vars` 里有没有密钥、端口是否被占用，
然后启动服务并在就绪后自动打开浏览器。**出现任何问题它都会在结尾停下等你按键**，
不会一闪而过；诊断时可以先跑 `启动.bat -Diagnose`（只做检查、不启动服务）。

可选参数：

```
启动.bat -NoBrowser        # 只启动服务，不打开浏览器
启动.bat -Port 5200        # 换端口（默认 5180）
启动.bat -Diagnose         # 只做环境检查
./start.sh --no-browser
./start.sh --port 5200
```

> ⚠️ **维护者注意**：`启动.bat` 与 `start.ps1` 必须保持**纯 ASCII**，不要往里加中文。
> cmd.exe 用系统代码页（中文 Windows 是 GBK）读取 `.bat`，而 Windows PowerShell 5.1
> 会把无 BOM 的 `.ps1` 当 ANSI 读；一旦文件里出现非 ASCII 字符，字符串字面量会被解码错乱、
> 脚本语法报错，用户看到的现象是"双击后窗口闪退"，极难排查。
> 中文提示属于网页界面，控制台输出保持英文。`npm run smoke` 里有护栏会拦住这个错误。

### 手动启动

```bash
npm install
cp .dev.vars.example .dev.vars   # Windows: copy .dev.vars.example .dev.vars
npm run dev                      # http://127.0.0.1:5180/
```

`.dev.vars` 需要填 `DEEPSEEK_API_KEY`（必需）、`ACCESS_PASSWORD`、`SESSION_SECRET`。
没有密钥也能启动，但提交批改会告诉你密钥缺失；此时可以点内置示例看批注效果。

其他命令：

| 命令 | 作用 |
| --- | --- |
| `npm run smoke` | 冒烟测试：批注位置校验、排版计算、反向验证，以及在 jsdom 里真正渲染界面并走一遍交互 |
| `node scripts/live-judge.mjs [1-3]` | 用真实 API 跑一次批改并打印警告细节，用于核对提示词与解析器 |
| `npm run typecheck` | 类型检查 |
| `npm run build` | 类型检查 + 生产构建 |

## 目录结构

```
src/
  domain/          领域逻辑，不依赖界面
    types.ts       题目、作答、批改、错误对象、四维度分等类型定义
    validate.ts    批注位置校验：确认 AI 指的位置确实存在，对不上就拒绝渲染
    layout.ts      把批改结果转成可渲染的片段序列，并消解互相重叠的批注
    color.ts       颜色分级
    prompt.ts      AI 提示词：字段格式、五种改法、分类表、评分标准
    parse.ts       解析 AI 返回的 JSON，结构不合格时给出可重试的具体原因
    ai.ts          DeepSeek 调用、重试策略、失败分类
    client.ts      前端调用 /api/judge 的封装
    mock.ts        五道内置示例题与示例批改（用于「查看内置示例批改」与冒烟测试）
  components/      界面
    App.tsx            左右两栏布局与流程编排
    ExerciseList.tsx   练习记录
    CorrectionPanel.tsx 分数、维度分、错误归类、逐处批注
    AnnotationText.tsx  批注渲染与调序弧线
    DetailPanel.tsx     点批注后弹出的解释
vite-plugin-judge-api.ts  本地开发用的 /api/judge（密钥只在服务端使用）
启动.bat / start.ps1      Windows 一键启动
start.sh                  macOS / Linux 一键启动
scripts/
  smoke.ts           冒烟测试的检查项
  render-probe.tsx   在 jsdom 中挂载界面并模拟交互（含批改接口的模拟响应）
  run-smoke.mjs      用 esbuild 打包后交给 Node 运行
  live-judge.mjs     用真实 API 跑一次批改，供人工核对提示词
```

## 实现进度

**已完成：句子翻译的最短闭环 + 真实 AI 批改**

- 左右两栏界面：左待译原文（含可折叠参考译文）、右作答输入
- 五种改法全部实现：替换、插入、删除、整句重写、语序调换（含配对弧线）
- 颜色分级：红（语法与严重表达不当）、橙（表达生硬）、绿（表达优秀，独立于错误统计）
- 修改风格切换：润色 / 精修
- 批改结果：总分、四维度分、总体与分维度评语、错误归类统计、逐处批注
- 点任意批注查看"错在哪类、为什么错"
- 练习记录：每次作答单独存档，可点进去回看当时的完整批改
- **批改由真实 DeepSeek API 完成**，密钥只在服务端使用
- AI 返回结果的解析与位置校验：不合格时把具体原因回传重试，最多 3 次
- 位置校验：AI 指的位置与译文对不上时拒绝渲染，并指出偏了几个字符
- 重叠批注消解：长跨度批注优先，避免划线上再划线
- 失败分类提示：密钥无效、余额不足、限流、超时、返回被截断，各自给出不同的下一步动作
