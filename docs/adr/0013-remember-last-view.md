# 记住"上次关掉网页时停在哪"，并且它优先于"从没批完的那一段继续"

打开网页时的落点现在从 `localStorage` 的 **`last-view`** 里恢复：
**栏 + 题 + 来源 + 第几页**四样一起记。用户的原话是
「默认落在第一个领域社会 + 英译中，然后个性化记忆，下一次落到上一次关掉时的界面」。

## 为什么是四样，一样都不能少

- **栏**：只记题会回到"文章栏的第一题"——他上次在句子栏，打开却到了文章栏。
- **题**：光有栏等于回到"该栏第一题"。
- **来源**：文章栏、内置题库、AI 出题、自己贴的题**共用同一个题号空间**
  （`art-…` / `article-001` / `gen-…` / `custom-…`）。只按题号取回来，可能取到**另一个来源的同号题**；
  按来源重新确认一遍，取不回来就当没记过（宁可回到默认落点，也不要停在一道不存在的题上）。
- **页**：不记页就等于把"上次关掉时的界面"降级成"这道题的第 1 页"。

内容没变时一个字都不写（`saveLastView` 里比对上一份序列化结果），
因此可以在**渲染时**顺手记一次，不必在切栏 / 换题 / 翻页 / 从记录跳回来这七八个入口各记一遍——
那种写法漏一个就前功尽弃（`lastInTabRef` 上已经踩过一次）。

## 它与两条既有规矩的先后

1. **「下次打开从没有翻译完成的那一段继续」**（ADR 0009 那轮定的）：
   这条现在是**兜底**——没记住页号时（第一次来、换了台电脑）才用它。
   记住了就以记住的为准，哪怕那一页已经批过、后面还有没批的。
   ⚠️ 实现上有个坑：兜底那条路给出的是**哪一篇**，没说"第几页"，
   把它当成"记住的第 0 页"会盖掉这条老规矩（实测过：进度里已批 3 页，打开却回到第 1 页）。
   因此落点里的 `sectionIndex` 类型是 `number | null`，null 才表示"没记住"。
2. **「整篇练完并批改过的文章不再被主动打开」**：这条**优先于**记忆。
   上次那篇练完了，打开时照样换到同一格里下一篇没练完的。
   判断只对**文章题**生效——句子题、术语题提交一次也会在进度里留下记录，
   但它们没有"整篇练完"这回事，不该被这条规矩拦在外面。

## 顺带清掉的一处重复

原先"上次是哪一篇"存在文章选择（`article-selection`）里，于是"当前这一篇"这个事有两份记录，
迟早会打架。现在那份只留**领域 + 方向**（文章栏那两个下拉要显示的东西），
"上次看到哪一篇、第几页"归 `last-view` 管——后者对句子栏、术语栏同样成立，
塞进那个只管文章栏下拉的文件里本来就不合适。存储键随之升到 `article-selection.v2`。

## 记录页与收藏页不记

它们是"去看别的东西"，不是练习位置。用户从记录页关掉网页，下次该回到他当时练的那道题，
而不是回到记录页。
