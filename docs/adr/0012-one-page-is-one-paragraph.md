# 文章模式：一页就是一个自然段

ADR 0009 定的分页口径（**100–200 单位一页**、不足 100 与下一段并、超过 300 按句切开）**作废**。
现在的规则只有两条，由用户在两轮里分别定下：

1. **一页 = 一个自然段**（用户原话："把每个文章进行分段，文章模式下，一段一段的出"）；
2. **不足 50 单位的自然段与相邻段合并**（在四个候选阈值里选了 50）。

实测：48 篇共 222 个自然段，切出 **201 页**，其中 **180 页（90%）就是一个自然段**。
页数分布是 3 页 9 篇／4 页 23 篇／5 页 14 篇／6 页 2 篇——比上一批"每篇 6–9 页"短得多，
因为那批新闻全文上千词，这批材料一篇只有 300–470 单位。

## 为什么把上限也去掉

上一轮那套规则的存在理由是"一页别太长也别太短"，而它自带两个补丁：
并进来会超上限、尾巴只剩两行要重新均分。这一轮换了口径之后这两个补丁都不需要了——
**自然段本身就是练习单位的边界**，用户看到的就是文章的段落结构。
因此 `PAGE_RULE` 只剩一个数字（`mergeBelow: 50`），`splitLongSection`（按句切开超长段）
整个删掉：这份材料最长的自然段 231 单位，本来也用不上。

## 阈值选 50 的理由（实测）

| 阈值 | 切出的页数 | 备注 |
| --- | --- | --- |
| 40 | 222 | 几乎就是纯粹的一段一页 |
| **50** | **201** | 只并掉 23 个明显破格的短段 |
| 60 | 210 | 英文段中位数只有 64 词，会有一半左右的英文段被并掉，段落感明显变弱 |
| 100 | 117 | 等于回到"两三段一页"，"一段一段出"就没了 |

## 参考译文跟着一起切

`paginateArticle(source, reference, direction)` 现在**多收一个参考译文**，
返回的每一页除了 `text`，还带一份 **`pairs`**：这一页里逐段配好的"原文 + 译文"。
留到这一层而不是渲染时再切，是因为一页可能由两个短自然段并成——
到那时候已经分不清哪句对哪句了。原文栏的「对照译文」直接铺它，练习记录页要整段译文时
用 `referenceOfPage` 从同一份数据里拼。

## 验收：在实现之外另写一遍规则再逐页对照

`scripts/check-articles.mjs` 不满足于验几条不变量（"不许有小页"这种是**能蒙过去的**：
把整篇并成一页也不违反它）。它按用户口径**手写一遍分页**（从左往右攒、够了收口、
末尾太短并进前一页），再要求实现逐页、逐段数都对上。冒烟测试里另有两个小样本把边界钉住：
三段各 22 字并成一页、一段 30 句的超长自然段**原样当一页**（不切）。
