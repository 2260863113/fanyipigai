# 分数按比赛标准给，分四个维度，不做趋势图表

每次批改固定输出：总分（0–100）+ 四个维度分（术语准确、语法正确、语篇连贯、语体得体）+ 总体评语 + 各维度评语。评价尺子**固定为比赛评分标准**，不提供四六级/专八等其他尺子。

## 为什么是比赛标准

同一个尺子不同，同一篇译文可能差 30 分。既然练习的唯一目的是参赛，尺子就必须是比赛那把。代价是分数看起来偏低、比较打击人——这是有意接受的：一个让人舒服但和真实成绩脱节的高分是安慰剂。

## 为什么是这四个维度

它们对应比赛公开的考查方向（语言基本能力、术语翻译及阐释、翻译策略及原则运用），因此维度分本身就有诊断价值——能看出拖后腿的是术语还是语法，而不是只知道一个总分。

## 为什么放弃趋势图表

练习记录保留（存服务端、可回顾完整批改、可重做），但**不画曲线、不做雷达图**。理由是使用者明确不要：练题时最需要的是"这一处为什么错"，而不是"我这三个月的分数斜率"。保留记录的价值在于回顾单次批改与统计弱项分类，不在于可视化。

## 连带影响

弱项统计只做**分类计数**（如"冠词/介词类错误最多"），这要求错误分类表固定、且一条错误只归一类；否则统计出来的是同义词碎片而不是弱项。
