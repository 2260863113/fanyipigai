# 去掉访问口令：站点对所有人开放

## 决定

拆掉整道口令门：删掉 `src/server/gate.ts`、`src/server/session.ts`、`src/server/pages.ts`、
`functions/login.ts`、`functions/logout.ts`，`functions/_middleware.ts` 只留三行安全响应头。
Cloudflare 项目上那两个 Secret（`ACCESS_PASSWORD`、`SESSION_SECRET`）一并删除。

用户的原话：

> 请你去掉进入口令这一环节，任何人都可以访问

## 代价（这条 ADR 存在的理由）

**任何拿到网址的人都能用站主的 DeepSeek 余额批改。** `*.pages.dev` 是公开的域名空间，
被扫描器扫到是常态而不是意外；从"有人发现"到"余额被刷"之间**没有任何一道拦阻**。
每次批改实测 6–35 秒、按 token 计费，被脚本循环调用时是持续支出。

这不是推翻了 ADR 0026 的理由，而是**取舍变了**。0026 写的是"缺配置时宁可不给进，也不放行"，
防的正是这件事；用户看到那个取舍之后明确选择了开放，理由也清楚——**点开就能用**比什么都重要，
而这一步的代价是可控的（余额用完就停，不是数据泄露）。因此这里如实记下来：
风险是被**知情地接受**的，不是被忽略的。

顺带说一件随之消失的事：原先那串口令**里嵌着完整的 API 密钥**（口令 = 密钥 + 6 个字符，
签名密钥 = 密钥 + 8 个字符）。门拆掉、两个 Secret 删掉之后，这条"看到口令就等于拿到密钥"
的路径也就不存在了。密钥本身从未进过 git 历史，也没出现在任何落盘文件里（全盘扫过）。

## 想收回来怎么办

ADR 0026 的实现**完整留在 git 历史里**（提交 `50b7622`），`git revert` 那个提交即可恢复原状。
若只想给 API 加一道闸、不再要登录页，更轻的做法是加在 Cloudflare 那一层：
Rate limiting 规则（按 IP 限速）、或给 `/api/*` 挂一个 Turnstile 校验。
两者都不需要改这个仓库的任何一行代码。

## 现在还剩什么

`functions/_middleware.ts` 不再是"门"，只补三个响应头：
`X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`、`Referrer-Policy: no-referrer`。
它们与"要不要登录"无关，防的是另一类事（类型嗅探、被 iframe 套住骗点击、地址外泄），
因此留着。

## 验证

- 冒烟测试删掉了原来 28 项口令/凭证/放行判定的检查（它们测的东西已经不存在了，
  留着最坏的结果是让人以为门还在），剩 **792 项**全部通过；`typecheck`、`build` 通过。
- 线上：`GET /` 直接 200（不再 302 去 `/login`）；**不带任何 cookie** 的一次真实批改
  也跑通——这正是"任何人都可以访问"的字面验证。
